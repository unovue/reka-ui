# packages/plugins

## Scope
Nuxt module, auto-import resolver, namespaced exports generator.

## Directory Structure
- `src/resolver/index.ts` — unplugin-vue-components resolver.
- `src/nuxt/index.ts` — Nuxt module (`@reka-ui/nuxt`).
- `src/namespaced/index.ts` — **auto-generated** namespaced exports.
- `src/namespaced/generate.ts` — script that generates `namespaced/index.ts`.

## Resolver Behavior
- Reads component list from `reka-ui/constant`.
- Matches prefix + component name → returns `{ name, from: 'reka-ui' }`.
- Keep `ResolverOptions.prefix` default `""`.

## Nuxt Module Behavior
- Registers components via `addComponent()` from `@nuxt/kit`.
- Respects `ModuleOptions.components` (boolean or partial map).
- Applies `ModuleOptions.prefix` to registered names.
- Config key: `reka`.

## Namespaced Generation
- `src/namespaced/index.ts` is generated by `pnpm --filter plugins generate`.
- **Do not hand-edit** this file.
- Excluded from namespacing: `configProvider`, `primitive`, `visuallyHidden`.
- Generation reads `reka-ui/constant` → groups by component family.

## Sync with Core
When component list changes in `packages/core/constant/components.ts`:
1. Run `pnpm --filter plugins generate` to regenerate namespaced index.
2. Run `pnpm --filter plugins build` to rebuild.
3. Run `pnpm lint` to verify.

## Verification Commands
- `pnpm --filter plugins generate` — regenerate namespaced exports.
- `pnpm --filter plugins build` — build plugins (unbuild).
- `pnpm lint` — ESLint.

## Do-Not-Edit
- `src/namespaced/index.ts` — auto-generated.
- `dist/**` — build output.
- `node_modules/**` — dependencies.
