# Baseline, 2026-11-25

- `baseline-v2.*`: origin/v2 `9025f41a9`. `baseline-v3.*`: origin/v3 `8eecd9769`. `baseline-v2-rerun.*`: v2 again, mount scenario only.
- `noise-floor.md`: `bench:compare` of the two v2 runs. `v2-vs-v3.md`: `bench:compare` of v2 and v3.
- One page load and three rounds per family (`--runs 1 --rounds 3`), same machine, same Vue (3.5.46) for both builds.

**Timing: pending.** The machine never got quiet (1-minute load average 30 to 97 during these runs, one sleep event), so every file here is marked `timings: suspect`. Heap, DOM and component-update counts do not depend on load and are valid: between the two v2 runs heap differs by at most 0.2% and the counts are identical. Timings quoted below are indicative; rerun with `pnpm bench:core --gate 2` on a quiet machine to replace them.

## Ranked optimisation targets
